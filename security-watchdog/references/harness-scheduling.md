Notes
- Plain GitHub Actions `schedule:` shortest interval is 5 minutes; runs can be delayed; default branch only.
- Claude Code cloud scheduled tasks are research preview; docs say they cannot run more often than hourly, so a 30-minute cadence needs Desktop/local, `/loop`, or external cron with `claude -p`.
- Claude desktop and cloud tasks add a few minutes of deliberate start delay.
- Interactive sign-in credentials in `-p` mode: `--bare` ignores OAuth/keychain, so unattended CI needs an API key.

## Recommended portable pattern

This skill implements this pattern in `scripts/run.sh` and `scripts/run.ps1` (see SKILL.md step 8).

1. Use the vendor's local, per-machine scheduler if it supports 30 min (Claude Desktop task or `/loop`, Codex app task); otherwise fall back to OS cron/launchd/systemd calling the headless CLI. This is the only mechanism that works in every harness.
2. Cron line: `*/30 * * * * cd /path/to/project && <headless cmd> >> ~/.cache/skill-run.log 2>&1` (full path to binary, since cron has no PATH). On macOS use a launchd plist with `StartInterval` 1800.
3. Use a cheap model for the tick: `claude -p --model haiku`, `codex exec -m <mini>`, `opencode run -m <provider/small>`, `gemini -m flash-lite`. The tick only runs the cheap check (e.g. hash the lockfiles) and exits if nothing changed.
4. Escalation: only when the check finds work, hand off to a stronger model. Native route per harness: Claude `--agents` JSON with `model: opus`; Codex `.codex/agents/*.toml` with `model`; OpenCode `mode: subagent` with `model`; Gemini subagent `model:`. Harnesses without this: have the script call the headless CLI a second time with a stronger `--model`.
5. Keep the deterministic gate in a script, not in the model, so most ticks cost zero tokens.
6. Do not rely on cloud schedulers (Claude cloud, Cursor, Copilot, Devin, Codex web) for anything needing local files; they see only a fresh clone. Lockfile scanning of a local checkout needs a local run, or commit-based cloud runs that scan the cloned repo.
7. Unattended permissions: pre-allow only the needed tools (`--allowedTools`, `--sandbox workspace-write`, `permissions.allow`), never blanket yolo outside a throwaway box. Add a budget/time cap (`--max-budget-usd`, `--print-timeout`).
8. Cloud cadences are hourly at best (Claude, Copilot) so a 30-minute spec degrades to hourly there; say so in the setup text.
